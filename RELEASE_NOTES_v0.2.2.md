# LiDAR Research Atlas v0.2.2

v0.2.2 improves the presentation of the four main catalog tables without changing the 207-record catalog scope.

## Fixed

- Dataset, method, research-portal, and ecosystem tables now use the full available desktop content width.
- The misleading internal horizontal scrollbar has been removed on desktop layouts.
- Long table values wrap within their columns without unnecessary word splitting.
- Narrow screens retain horizontal scrolling where needed for readability.
- The generated Research Portals page now uses the same table wrapper as the other catalogs.
- Rendered-site regression checks now cover all four table pages.

Catalog scope remains 85 datasets, 53 methods, and 69 ecosystem resources.
