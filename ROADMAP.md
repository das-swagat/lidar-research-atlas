# Roadmap

## 0.2 — Catalog depth
- Expand high-impact datasets and methods using primary-source pull requests.
- Add class-taxonomy mappings and benchmark-task matrices.
- Add provider-approved thumbnails only where reuse rights are explicit.

## 0.3 — Research analytics
- Add versioned citation/adoption snapshots with retrieval dates.
- Add original charts on access barriers, environment coverage, modality, and task concentration.

- Add environment manifests, preprocessing fingerprints, and independently verified reproduction notes.

## 1.0 — Stable scholarly release
- Complete provenance audit.
- Archive a release on Zenodo and add DOI.
- Publish companion technical report/data record.
- Establish a documented maintainer review process.
