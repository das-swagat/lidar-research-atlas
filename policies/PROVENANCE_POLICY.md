# Provenance policy

Every factual catalog claim must be traceable to an authoritative source. The source register records resource, role, URL, verification date, and status. Secondary indexes may discover candidates but cannot alone establish ownership, license, access conditions, or official implementation status.

Copied abstracts and README prose are prohibited unless quotation is necessary, brief, attributed, and legally permitted. Default descriptions are independently written summaries.

## Discovery-layer records

A secondary scholarly list may be used to discover a candidate resource. The atlas must then:

1. retain the source collection in a machine-readable provenance field;
2. link to an official project, provider, publisher, or repository source where available;
3. write a new description instead of copying source prose;
4. mark unresolved contributor, publication, license, access, or maintenance facts as unverified;
5. use conservative access and redistribution labels;
6. promote the record to `partial` or `verified` only after direct source review.

An upstream list's inclusion, star count, or wording does not establish official status, permission, scientific quality, availability, or legal reuse rights.
