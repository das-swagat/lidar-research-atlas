# LiDAR Research Atlas v0.2.0

Expanded research release with 207 structured records:

- 85 dataset records
- 53 method records
- 69 ecosystem resources

This release adds searchable web tables, YAML/CSV/JSON exports, manufacturer/library/framework/simulator/tool coverage, broader indoor/outdoor and 2D/3D scope, a source-list comparison, and stricter discovery-layer provenance rules.

Records marked `discovery_only`, `source_listed`, or `partial` require direct provider verification before relying on access, licensing, commercial-use, contributor, or implementation-status fields. No third-party datasets, annotations, model weights, copied paper figures, credentials, or unofficial mirrors are included.

## Verification boundary

This release expands coverage using the two acknowledged upstream discovery collections, while preserving conservative verification labels. A `discovery_only` or `source_listed` entry is not a completed legal, licensing, access, or implementation determination.
