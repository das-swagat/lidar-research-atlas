# LiDAR Research Atlas v0.1.0

First curated scholarly release of an indoor/outdoor, 2D/3D LiDAR research atlas.

## Included
- 27 dataset records and 27 method records.
- Original, professional documentation theme and conceptual vector diagrams.
- Official-source links, access classes, legal-use summaries, citation guidance, and verification dates.
- Separate identification of official, author-maintained, framework, and community implementations.
- Structured YAML, JSON, and CSV metadata exports.
- GitHub Pages deployment, validation, restricted-file scanning, tests, issue forms, and release guidance.

## Boundary
This release contains no third-party scans, labels, model weights, credentials, signed download links, or copied paper figures. It is a curated starter release and not an exhaustive census. Entries marked `partial` require re-verification before stable 1.0 claims.
