# Catalog

The v0.2.1 catalog contains structured YAML records for:

- `datasets/` — 85 indoor, outdoor, 2D, 3D, aerial, mobile, terrestrial, automotive, robotic, and synthetic datasets;
- `methods/` — 53 perception, registration, segmentation, detection, odometry, SLAM, place-recognition, self-supervised, and calibration methods;
- `ecosystem/` — 69 manufacturers, libraries, frameworks, simulators, tools, and related curated lists;
- `portals/` — authoritative discovery and cloud-access portals.

Records marked `discovery_only` or `source_listed` are broad coverage leads, not completed license or access determinations. Run `python scripts/validate_catalog.py` and `python scripts/build_catalog.py` after changes.
