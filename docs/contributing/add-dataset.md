# Add a dataset

1. Copy one YAML file in `catalog/datasets/`.
2. Use a stable lowercase identifier.
3. Add original contributors and authoritative pages.
4. Identify geometry, environment, sensors, and tasks.
5. Separate access, commercial use, redistribution, and license.
6. Add only provider-supported access steps.
7. Set `partial` when any material field remains uncertain.
8. Generate documentation and submit sources in the pull request.

Never upload the dataset itself.
