The expanded atlas is intentionally split into three layers.

## Dataset layer

The dataset catalog covers autonomous driving, mobile robotics, indoor mapping, aerial and terrestrial scanning, off-road navigation, construction, adverse weather, long-term localization, place recognition, heterogeneous LiDAR, moving-object segmentation, and synthetic data.

## Method layer

The method catalog spans point representations, semantic segmentation, ground segmentation, moving-object segmentation, 3D detection and tracking, registration, odometry, SLAM, place recognition, self-supervised learning, and sensor calibration.

## Ecosystem layer

The ecosystem catalog tracks manufacturers, libraries, autonomous-system frameworks, simulators, annotation and visualization tools, and neighboring curated lists.

## Interpretation caution

Coverage is broad, not exhaustive. Count alone is not a quality claim. The atlas exposes verification status so that users can distinguish source-listed discovery records from independently reviewed records.
