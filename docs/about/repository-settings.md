# Recommended GitHub settings

## About panel
**Description:** `A provenance-tracked atlas of indoor and outdoor 2D/3D LiDAR datasets, methods, benchmarks, and lawful access guides.`

**Website:** `https://das-swagat.github.io/lidar-research-atlas/`

**Topics:** `lidar`, `point-cloud`, `robotics`, `computer-vision`, `slam`, `semantic-segmentation`, `3d-object-detection`, `self-supervised-learning`, `autonomous-driving`, `geospatial`, `datasets`, `research`

## Features
Enable Issues and Discussions. Disable Wiki unless it will be actively maintained. Protect `main`, require pull requests and passing validation, and prevent force pushes.

## Pages
Use GitHub Actions as the deployment source. The included `docs.yml` workflow builds and deploys the MkDocs site.

## Social preview
Upload `docs/assets/images/social-card.png` in repository settings after the first push.
