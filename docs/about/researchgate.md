# ResearchGate publication mapping

After a stable GitHub release and archival DOI, create original scholarly outputs rather than uploading third-party data.

## Data item
**LiDAR Research Atlas Metadata: Indoor and Outdoor 2D/3D Datasets, Methods, Benchmarks, and Access Conditions**

Include frozen catalog YAML/CSV/JSON, schema, methodology, source register, and original charts. State explicitly that no third-party scans, labels, weights, or restricted files are included.

## Technical report or preprint
**The LiDAR Research Landscape: Indoor and Outdoor 2D/3D Resources, Access Conditions, and Reproducibility Trends**

Analyze versioned atlas metadata, explain methods and limitations, cite every original source, and link the GitHub release/DOI. Label the item accurately as a technical report or preprint unless peer reviewed.
