# Cite the atlas

GitHub can render `CITATION.cff` as a “Cite this repository” control. Until a DOI is assigned, cite version 0.2.0 using the repository URL and release date. After Zenodo archives a GitHub release, update `CITATION.cff`, `.zenodo.json`, and this page with the DOI.

The atlas citation is supplementary. It never substitutes for original dataset or method citations.
