# Methodology

## Inclusion
A resource is included when it has scholarly, technical, historical, or domain-coverage value and a defensible authoritative source. Popularity may inform discovery priority but does not determine scientific relevance.

## Evidence hierarchy
1. Provider license/terms and official landing page.
2. Primary publication and author project page.
3. Official or author-maintained repository.
4. Institutional archive or benchmark documentation.
5. Secondary indexes only as discovery aids.

## Verification labels
- `verified`: core catalog claims checked against authoritative sources on the recorded date.
- `partial`: one or more material access, license, authorship, or implementation details require rechecking.

## No synthetic precision
The atlas does not publish a popularity score until citation, benchmark, repository, and search signals have reproducible collection methods and dated snapshots.
