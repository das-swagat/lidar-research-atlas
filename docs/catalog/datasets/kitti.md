## Lawful access workflow
1. Open the official page linked above.
2. Read the current provider terms and confirm eligibility.
3. Create an account or submit the provider agreement when required.
4. Download only through provider-supported links or tools.
5. Obtain labels, calibration, maps, and development kits from their separately identified official sources.
6. Verify file integrity when provider checksums are available.
7. Preserve the original folder structure and citation notice.
