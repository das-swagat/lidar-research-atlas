# Reproducibility checklist

- Dataset name, provider, version, subset, and retrieval date.
- Terms/license version accepted and access class.
- Official source URLs and checksums where supplied.
- Sensor topics, coordinate frames, timestamps, calibration, and units.
- Train/validation/test split and excluded sequences.
- Label map, ignored classes, and class remapping.
- Preprocessing code revision and deterministic configuration.
- Method paper, implementation relationship, commit hash, environment, and weights source.
- Metrics, evaluation script/version, hardware, seeds, and known deviations.
- Original dataset and method citations.
