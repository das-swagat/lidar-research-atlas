# Citation and attribution

## Required order

1. Cite every original dataset publication and any additional references required by its provider.
2. Cite every original method paper used or compared.
3. Cite an implementation when its maintainers request a software citation or when the implementation materially differs.
4. Cite the atlas only when its metadata, taxonomy, guide, code, or analysis materially supported the work.

Never replace the original creators' citation with the atlas citation.

## Reuse attribution
For openly licensed third-party material, record Title, Author, Source, License, and modifications. The default atlas release includes original conceptual diagrams rather than copied paper figures.
