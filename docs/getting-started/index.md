# Get started

Use the atlas as a research-navigation layer, not as a substitute for original papers or licenses.

1. Define the environment, sensor geometry, task, annotation needs, and permitted use.
2. Shortlist resources in the dataset catalog.
3. Open the authoritative provider page and current terms.
4. Follow the lawful access workflow.
5. Read the original paper and official development-kit documentation.
6. Record the dataset version, retrieval date, checksums, preprocessing, and required citations.
