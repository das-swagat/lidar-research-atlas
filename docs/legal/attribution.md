# Attribution policy

Every record separates:

1. **Original dataset contributors** — creators, provider, publication, official page, required citation.
2. **Original method authors** — paper authors, venue/source, publication, project page.
3. **Implementation maintainers** — official, author-maintained, community reimplementation, or framework integration.
4. **Atlas contributors** — metadata curation, taxonomy, verification, original summaries, tooling, and analysis.

The atlas must never imply that its maintainers created an indexed method, dataset, benchmark, or implementation.
